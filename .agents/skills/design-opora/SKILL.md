# Дизайн «Опоры»: анти-слоп арт-дирекшн

Этот скилл — обязательный контекст для любой визуальной работы в репозитории. Он собран из
процесса Anthropic `frontend-design`, анти-слоп правил Hallmark/Taste Skill, floor-требований
Vercel Web Interface Guidelines и бренд-решений «Опоры» (docs/design/*).

## Когда использовать

- Новый экран/компонент, редизайн лендинга, онбординга, `/app`, писем, юридических страниц.
- Ревью визуала: «выглядит как нейрослоп», «нет характера», «не похоже на бренд».
- Перед сдачей UI-задачи (вместе с `docs/DEFINITION_OF_DONE.md`).

Сначала прочитай: `docs/design/diagnosis.md`, `docs/design/references.md`,
`docs/design/direction-v2.md`, `docs/planning/11-copy.md`, `docs/planning/10-design.md`.

## Жёсткие правила бренда (нарушать нельзя)

- Аудитория: женщины 25–45 (ядро 28–40), РФ. Тон тёплый, взрослый, «ты», без сюсюканья.
- **Не медицина:** никаких «лечение/терапия/диагноз/избавит/вылечит/клинически доказано»,
  обещаний результата, названий препаратов и диагнозов.
- ПДн — специальная категория: дизайн не должен провоцировать лишний сбор данных; приватность
  объясняем спокойно и по делу.
- Мобайл-фёрст с 360 px; тач-зоны ≥ 44 px; контраст AA; видимый фокус; `prefers-reduced-motion`.
- Копирайт — из `11-copy.md`; не переписывать смысл и не добавлять обещаний.

## Палитра v2 (Direction B, «Прохладная бумага и мох»)

`ink #1B201B` · `paper #F1F1EA` (прохладная бумага, НЕ крем) · `moss #46543F` · `moss-deep #2F3A2C` ·
`moss-soft #DDE2D6` · `wine #6C2A30` · `sage #A8B3A0` · `sand #E4E0D4` · `line #D5D2C6` ·
`danger #A64B4B`.

Правила: `wine` — не больше ~8% площади, только сигнал/CTA (текст на нём — paper); `moss` —
архитектура (поля, футер, dark-секции); никаких градиентов, glassmorphism, неона, розово-лиловых
схем и «крем #F7F3EE + терракота #B4654A + сериф» по умолчанию (это AI-телль №1).

## Типографика

- **Onest ведёт** — заголовки H1–H3, лиды, UI/кнопки/поля, навигация (гротеск-голос, не AI-дефолт).
  **Literata — только «событие»**: цитаты, уроки, письма, дневниковые заготовки, отчёт. IBM Plex Mono —
  цифры/даты/счётчики (tabular-nums). Не больше двух основных семейств.
- Шкала: H1 40→72 (Onest 500/600, tracking −0.02em), H2 30→44, H3 22→28, lead 19→22 (Onest),
  reading 17/28 (Literata), UI-body 16/24, caption 13/18, meta 12/16 (Plex Mono).
- Строка 58–68 знаков; `text-wrap: balance` у заголовков; италик — на целой фразе, не на слове.

## Композиция

- Сетка 12 колонок, max 1280, поля 64/40/20, gutter 24/20/16; шаг 8 pt.
- Ритм секций чередуется: paper → forest-поле → фото full-bleed → paper; асимметрия 5/7, 4/8.
- Линии вместо карточек: редакционные строки, hairline-разделители, подписи на полях.
- Карточка — только интерактивный модуль: рамка 1px `line`, радиус 8, **без тени**; hover — граница
  + сдвиг стрелки. Радиусы: контролы 6, медиа 8, теги pill.
- Кнопки: 48–56 px, радиус 8; primary — ink/forest с paper-текстом или honey с ink-текстом;
  secondary — подчёркнутая ссылка. Не добавлять `→` в каждую кнопку.

## Медиа

- Фото: реальные женщины 30–45 в обычных ситуациях (окно, чай, руки, плед, дорога, свет),
  естественный свет, плёночное зерно; без слёз, постановочных улыбок, романтических пар.
  Кропы 3:4 / 4:5 / 3:2; full-bleed hero.
- До арт-фотосессии — временные натюрморты (свет, лён, чашка) с честной пометкой в задаче.
  Unsplash/Pexels нельзя подбирать AI-инструментом по ToS; Wikimedia/CC или заказная съёмка.
- Иллюстрация: один язык (чернильная линия + одно пятно), 2–3 места максимум. Никаких абстрактных
  арок/пузырей как главного героя. Alt-текст обязателен.

## Движение

- Один сценарий на страницу (hero: 400–600 ms, ease-out-quint). Никаких fade-up на каждой секции
  и hover-подъёма карточек. Анимируем только transform/opacity; reduced-motion отключает всё.

## Процесс (два прохода, как у арт-директора)

1. **План токенов в 3–5 строк**: цвет (4–6 hex), шрифты и роли, композиция (ASCII-эскиз),
   один принцип, который отличает экран. Сверить с брифом.
2. **Ревью на дефолтность**: пройди анти-слоп чек-лист; если решение получилось бы у любого
   AI по такому же промпту — переделай и запиши, что изменил.
3. **Сборка**: один смелый жест на экран, остальное тихо; состояния default/hover/focus/disabled/
   loading/error/empty; реальные тексты, не lorem ipsum.
4. **Проверка**: скриншоты 360/768/1440 + axe + чек-лист; для интерактивных экранов — Playwright.

## Анти-слоп чек-лист (блокирует сдачу)

- [ ] Нет дефолта «крем + терракота + высококонтрастный сериф»; палитра имеет причину.
- [ ] Нет ALL-CAPS-«бровей» над каждым заголовком и акцентного цвета на одном слове.
- [ ] Нет иконок в светлых «чипсах» над каждой карточкой.
- [ ] Нет одинаковых скруглённых карточек с одной тенью на любой контент; нет `→` в каждой ссылке.
- [ ] Номера/маркеры — только если контент действительно последовательность.
- [ ] Нет fade-up на всех секциях и hover-подъёма карточек.
- [ ] Есть один запоминающийся элемент (прохладное цветовое поле, фото, гротеск-сцена, тактильный слой).
- [ ] Медиа осмысленны: арт-фото/иллюстрация, а не декоративная «органика».
- [ ] Тексты — по `11-copy.md`, без медицинских формулировок и обещаний.
- [ ] AA-контраст, фокус, 44 px, 360 px без горизонтального скролла, reduced-motion.
- [ ] Скриншоты приложены; axe 0 critical/serious.

## Если сомневаешься

Не изобретай декор — сократи. Один смелый жест, выверенная типографика и честные тексты
работают лучше, чем пять «красивых» приёмов. При новом решении — ADR + D-XXX в журнале.
