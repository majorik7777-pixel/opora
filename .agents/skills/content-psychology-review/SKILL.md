# AI-ревью психологического контента

Этот скилл — процесс и промпты для AI-проверки текстов «Опоры». Он снижает риск фактических ошибок,
медицинских формулировок и «инфоцыганства», но **не заменяет психолога-ревьюера** и не даёт права
указывать эксперта, которого нет. Юридические ограничения — `docs/planning/08-legal-pdn.md`,
`docs/reports/legal-check-2026-11-19.md`; тон — `docs/design/russian-adaptation.md §4.4`.

## Когда использовать

- Черновик статьи/урока/FAQ перед публикацией.
- Проверка лендинга и email на запрещённые обещания.
- Разбор «доказательств»: отзывы, цифры, комментарии специалистов.

## Жёсткие запреты (блокируют публикацию)

- «Лечение», «терапия» (о сервисе), «диагноз», «избавит», «вылечит», «клинически доказано»,
  названия препаратов/диагнозов, обещания результата («гарантируем», «навсегда избавитесь»).
- Выдуманные отзывы, «комментарии психолога», цифры пользователей, рейтинги, логотипы СМИ,
  сертификаты. Нельзя генерировать доказательства — только реальные с согласием.
- Советы, подменяющие врача: самолечение, отказ от помощи, «не ходи к врачу».
- Травмирующие подробности, романтизация расстройств, стыжение, давление, таймеры/дефицит.

## Иерархия источников (для проверки утверждений)

1. Официальные рекомендации ВОЗ/Минздрава РФ/Роспотребнадзора, клинические руководства.
2. Систематические обзоры и мета-анализы (Cochrane, PubMed), крупные лонгитюдные исследования.
3. Профессиональные ассоциации (РАПК/АКПП, APA, BPS) — методические материалы.
4. Учебники и обзоры для специалистов.
5. Научно-популярные источники — только как пояснение, не как доказательство.

Каждое фактическое утверждение в статье — с источником; спорное — с оговоркой «по данным…»,
без категоричности. Не приписывать источникам то, чего в них нет.

## Процесс ревью (для агента)

1. **Извлеки утверждения.** Список: «утверждение → тип (факт/мнение/совет) → источник → риск».
2. **Проверь факты.** Для каждого факта — ссылка на источник; если источника нет — пометь
   «требует источника» и не публиковать.
3. **Проверь язык.** Найди запрещённые формулировки и обещания; предложи безопасную замену.
4. **Проверь пользу и вред.** Нет ли советов, опасных для человека в кризисе; есть ли направление
   к специалисту/телефонам помощи при тяжёлых состояниях.
5. **Проверь E-E-A-T-поля.** Автор, ревьюер (реальный человек!), дата публикации/обновления,
   источники, дисклеймер, «не медицина».
6. **Дай вердикт:** `publish`, `publish with edits`, `needs human review`, `reject` — с причинами.

## Промпты

### A. Аудит черновика

```
Ты — научный редактор сервиса психологической самопомощи (не медицина).
Текст: <вставить>.
1) Выпиши все фактические утверждения и советы.
2) Для каждого: есть ли источник в тексте; если нет — какой источник нужен (ВОЗ/обзор/руководство).
3) Найди запрещённые формулировки: лечение, терапия, диагноз, избавит, вылечит, гарантии, обещания результата.
4) Найди места, где текст может навредить человеку в кризисе; предложи безопасную формулировку и направление к помощи.
5) Проверь тон: «ты», без стыда и давления, без «инфоцыганства» (трансформация, прорыв, ресурс).
Верни JSON: {claims:[], forbidden:[], risks:[], edits:[], verdict:""}.
```

### B. Проверка источников

```
Ты — фактчекер. Для каждого утверждения ниже найди первичный источник (ВОЗ, рецензируемый обзор,
официальные рекомендации). Не выдумывай ссылки: если не уверен — напиши «не найдено».
Утверждения: <список>. Верни таблицу: утверждение | источник | статус (подтверждено/опровергнуто/нет данных).
```

### C. Проверка «доказательств» на лендинге

```
Проверь блок доказательств: отзывы, цифры, «комментарий психолога», рейтинги, логотипы.
Для каждого: реальный ли источник, есть ли согласие, можно ли проверить.
Фейковые/непроверяемые — пометь «удалить». Предложи легальную замену: история основателя,
прозрачная методология, реальные метрики после запуска, отзывы с согласием.
```

### D. Юридический чек-лист текста

```
Проверь текст на: медицинские обещания; специальную категорию ПДн; 18+; отсутствие реквизитов
оператора; отсутствие согласия на обработку; недостоверную рекламу. Верни список нарушений и
безопасные формулировки.
```

## Ограничения и эскалация

- AI может ошибаться и «галлюцинировать» источники — ссылки проверяются вручную.
- Для статей и программы нужен **реальный** психолог-ревьюер; до его появления в E-E-A-T-полях
  писать «редакция», не выдумывать эксперта.
- При сомнениях в безопасности (суицид, насилие, расстройства) — только `needs human review` и
  кризисный протокол (112, МЧС 8 495 989-50-50, РКК 8 800 250-18-59).
- Результат ревью — в задаче/PR, а не только в чате.
