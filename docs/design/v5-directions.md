# v5: три направления языка (к выбору основателя)

Дата: 20.11.2026 · Основание: `anti-slop-v5.md` · Макеты: `scratch/opora-v5/*.html` (не в репозитории)

Задача: выбрать язык, который нельзя перепутать с «аккуратным AI-сайтом». Все три собраны на реальном
копирайте (`11-copy.md`), реальных шрифтах (Onest + Literata), с продуктом на первом экране.

## A «Архив» — книжно-редакционный

Светлая бумага `#F1ECE1`, Literata в заголовке, волосяные линии вместо карточек, поля с метаданными,
индекс дней 01–07, тёмное лесное поле `#2C3F35` только под CTA. Продукт — «лист документа» с рамкой
и сдвигом на 0.5°, без тени.
Механика: читается как русский журнал/книга, доверие без «велнеса».
Риск: «крем + антиква» — сам по себе AI-телль; держится только на холодном зелёном, тонких правилах
и точной типографике. Продукт выглядит чуть менее «живым», чем в B.

## B «Ночная комната» — тёмное поле, продукт как свет

Ночной фон `#141719`, зерно в screen, гигантский H1 (Onest 500, 104 px) с курсивной Literata на
«себя», янтарь `#D08C4E` как единственный свет. Продукт — светлый лист в тёмной комнате, единственная
яркая поверхность.
Механика: попадает в реальный контекст — листают телефон ночью; продукт = свет.
Риск: «тёмный премиум» — тоже распространённый шаблон; и для человека в плохом состоянии тёмный
экран + огромный кегль может давить.

## C «Плакат» — антагонист и жест

Кремовая бумага + холодная синяя плашка `#1B2E42` на весь первый экран, H1 в капсе до 150 px,
контурная «07» в фоне, белая карточка продукта наезжает на стык блоков, ценовой блок — чёрная плита
с янтарной цифрой. Радиусы 0, один pill-тег как контраст.
Механика: максимальная неотличимость от конкурентов, плакатная уверенность.
Риск: капс + синий + огромный кегль читается как «агрессивный финтех»; для уязвимой аудитории может
быть слишком громко.

## Рекомендация

Собрать **A как основу** (типографика, правила, индексы, тон) и взять из **C один плакатный приём** —
холодное поле на секции «приватность/цена» и контурную цифру дня; из **B** — светлый продукт как
единственную яркую поверхность на тёмной секции финала.

Так язык получает: книжную основу (не слоп), один тёмный антагонист (не монотонно), один жест
(не безлико) — без капса на весь экран и без «ночного премиума» целиком.

## Проверка перед внедрением

- тест «убери логотип»: по картинке понятно, что это про расставание, а не клиника/банк;
- 70% светлого / 20% тёмного / 10% акцента;
- ни одного fade-up, hover-подъёма и счётчика; одна структурная сцена на страницу;
- AA на всех текстах, 360 px без горизонтального скролла, reduced-motion → статика.
