# Дизайн «Опоры» v2 — материалы к редизайну

Дата: 19.11.2026 · Статус: **на согласовании с основателем** · Phase: до T-101

Причина пакета: текущий дизайн Phase 0–1 читается как «нейрослоп» — он собран из дефолтных
AI-приёмов (кремовый фон + терракотовый акцент + высококонтрастный сериф, одинаковые скруглённые
карточки с тенями, симметричные сетки, декоративная «органика»), а не из арт-директорского решения.
Подробный разбор — [`diagnosis.md`](diagnosis.md).

## Процесс редизайна (после выбора направления)

1. **Решение**: основатель выбирает направление (B рекомендуется) и ограничения (фото/иллюстрации).
2. **Токены и типографика**: `packages/ui` + `globals.css` переводятся на v2 (T-201).
3. **Лендинг**: новая композиция и арт-дирекшн (T-202).
4. **Онбординг/auth/`/app`**: те же принципы, без «дашборда из карточек» (T-203).
5. **Арт-дирекшн ассетов**: фотобриф/съёмка или лицензированные кадры, 1 язык иллюстрации (T-204).
6. **Дизайн-QA**: скриншоты 360/768/1440, axe, анти-слоп чек-лист, визуальные снапшоты (T-205).

Не начинать редизайн, пока не выбрано направление и не зафиксировано решение D-032 в журнале.
