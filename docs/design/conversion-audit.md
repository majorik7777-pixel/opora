# Продающий аудит лендинга v2 и план v3

Дата: 19.11.2026 · Автор: лид · Статус: обсуждение с основателем · Код не менялся (ждём фото)

## 1. Честный ответ: да, ещё читается как «дизайнерский шаблон»

После первого редизайна ушли прямые AI-телли (крем + терракота + Lora, карточки с тенями,
капс-брови, `→`). Но остались признаки **редакционного шаблона**, а не собственного бренда:

1. **Грамматика «красивого журнала»:** огромный гротескный заголовок + италик-цитата + номера
   01–03 + hairline-строки. Это воспроизводимая формула (Dribbble/Awwwards/Framer-шаблоны),
   её может собрать любая модель. Нет приёма, который принадлежит только «Опоре».
2. **Визуальный язык не связан с продуктом.** Палитра «прохладная бумага + мох + вино» и
   типографика Onest/Literata подошли бы скинару, ретриту или книжному издательству. Проверка на
   слоп: поменяй тексты — и страница продаст что угодно «спокойное и премиальное».
3. **На первом экране нет продукта и человека.** Вместо доказательства — типографический плакат.
   Красиво, но не отвечает на вопросы «что я получу? как это выглядит? почему тебе можно верить?».
4. **Холодно.** Тёмно-моховый первый экран + вино + прохладная бумага для женщины в уязвимом
   состоянии могут читаться как «эко-бренд/издательство/офис», а не «тепло и поддержка».
   Тепло предыдущей версии (хоть и слопной) потерялось.
5. **Нет продающей архитектуры:** один CTA в hero и один у цены, нет демонстрации продукта,
   доказательств, снятия риска рядом с ценой, липкого мобильного CTA; оффер «первый день
   бесплатно» спрятан в мелкий текст.
6. **Повторяемость:** четыре секции подряд — «заголовок слева + список справа». Нет контраста
   форматов, кроме тёмной полосы; взгляд не ведут.

Вывод: это хорошая **база визуального языка**, но не продающий лендинг. Нужен слой v3 —
продуктовый, человеческий, с оффером и доказательствами.

## 2. Pinterest: что показал разбор

- Поиск «therapy website design» на Pinterest — это море одинаковых терапи-шаблонов: sage-green,
  серифные заголовки, мягкие фото, «compassionate therapy», Squarespace. Наш мох + сериф + бумага
  в этом ряду **сливаются**, а не выделяются.
- Значит, Pinterest полезен как насмотренность по композиции/фото, но копировать нишевую эстетику
  нельзя — получим ещё один «tasteful AI» сайт.
- Прямой скролл Pinterest без логина ограничен (модалка). Скриншоты поиска сохранены в
  `design-references/pinterest/` (вне репозитория).
- Основатель упоминал подборку Pinterest из прошлого чата DeepSeek — **нужна ссылка/скриншоты**,
  чтобы разобрать именно те референсы, а не абстрактный поиск.

## 3. MCP: что реально можно подключить

DSH умеет подключать MCP-серверы конфигурационным бандлом (`@deepseek-ai/dsh-mcp-client`,
transport `streamable-http` или `stdio`). Проверенные варианты:

| MCP | Что даёт | Что нужно | Полезность для нас |
|---|---|---|---|
| **Figma MCP** (официальный) | читать фреймы/переменные/компоненты, генерировать код, писать на канвас | Figma-аккаунт и файл; remote `https://mcp.figma.com/mcp` (OAuth) или desktop-сервер (нужен Dev/Full seat); для записи — Full seat | Высокая: можно разобрать мудборд/референсы в Figma и собрать макет до кода |
| **Playwright MCP** (Microsoft) | браузер: открывать/скроллить/скриншотить сайты, извлекать стили | Node/npx, без аккаунта | Высокая: Pinterest/Are.na/Mobbin/siteinspire, разбор референсов, скриншоты |
| **Chrome DevTools MCP** | DOM/производительность/отладка | Chrome | Средняя: для QA, не для вкуса |
| **Canva MCP** | генерация макетов/презентаций | Canva-аккаунт | Низкая: не наш арт-дирекшн |
| Mobbin/Refero/Pinterest MCP | — | официальных MCP не подтвердил | Нет; работаем через браузер |

Важно: MCP даёт **доступ**, а не вкус. Реальный рычаг — Figma-файл с выбранными референсами +
реальные экраны продукта + фотографии. Если у основателя есть Figma — можно подключить и собрать
v3 сначала в макете; если нет — быстрее сделать 2 варианта в коде и сравнить скриншотами.

## 4. План v3: продающий слой (после фото)

**Не выбрасываем палитру/шрифты.** Меняем композицию и приоритеты:

1. **Hero — два варианта на сравнение:**
   - A (теплее): фон — бумага, слева оффер, справа фото реальной женщины + поверх карточка
     продукта (фрагмент чата/дневника). Мох — полосой ниже, не весь экран.
   - B (продуктовый): фото full-bleed + поверх крупный оффер и CTA + мини-скриншот приложения.
   - H1 — про результат и механику: «7 дней, чтобы перестать прокручивать это в голове —
     по 10 минут в день» (варианты протестировать).
   - CTA: «Пройти первый день бесплатно» + «без карты, анонимно».
2. **«Как это выглядит»:** 3 реальных экрана — чат с поддержкой, урок дня, дневник. Это главный
   продающий блок, которого сейчас нет.
3. **«Почему это работает»:** визуальная система 7 дней (7 меток/путь) — фирменный приём, связанный
   с продуктом, а не декор; коротко про структуру: урок → практика → дневник → поддержка.
4. **Доказательства без фейков:** методология, «не медицина», данные в РФ, возврат по оферте,
   позже — реальные отзывы с согласием. Никаких «4,9★» и таймеров.
5. **Оффер:** цена 990 ₽ ближе к hero; состав; возврат в течение 7 дней — рядом с CTA; «без
   подписки»; способы оплаты; повтор CTA после блока цены и в конце; липкая кнопка на мобильном.
6. **Тепло:** больше фото, меньше пустого мха; мох — акцент; вино — только CTA; убрать огромные
   пустые поля первого экрана; текст крупнее и ближе к человеку.
7. **Проверка:** 2 варианта hero → скриншоты 360/768/1440 → 5 женщин 28–40 (вопросы из
   `russian-adaptation.md §6`) → выбрать; e2e + axe остаются зелёными.
