# Диагноз: почему текущий дизайн читается как «нейрослоп»

Дата: 19.11.2026 · Относится к Phase 0–1 (`apps/web`, `packages/ui`)

## 1. Главный тест

Официальный скилл Anthropic `frontend-design` называет первым признаком сгенерированного дизайна
ровно ту комбинацию, которая получилась у нас:

> «тёплый кремовый фон (около #F4F1EA) + высококонтрастный серифный заголовок + терракотовый/
> глиняный акцент (около #D97757) — на брифе Anthropic это выглядит как телль».

Наши значения: фон `#F7F3EE`, акцент `#B4654A`, заголовки — Lora. Это те же три дефолта, плюс
узнаваемый «Claude-акцент». Дизайн сделан добротно, но **не выбран под бриф**, а собран из
наиболее вероятных для LLM приёмов.

## 2. Остальные AI-телли в текущей реализации

| Телль | Где у нас |
|---|---|
| Одинаковые скруглённые карточки с одной тенью на любой контент | лендинг («Если сейчас так», «Что внутри»), быстрые действия в `/app` |
| Симметричные сетки 2–3 колонки, одинаковая высота секций | почти все секции лендинга |
| Иконка в светлой «чипсе» над каждой карточкой | «Что внутри», «Быстрые действия» |
| ALL-CAPS eyebrow над каждым заголовком | «ТВОЯ ОПОРА», «ЗНАКОМСТВО · 2 МИНУТЫ», «ДНЕВНИК · КАРКАС» и т.п. |
| Акцентный цвет на одном слове/куске заголовка | нет, но терракота разлита по всем акцентам |
| Абстрактная «органика» (круги, арки) как безопорная иллюстрация | hero-иллюстрация |
| Одинаковый fade/slide на всех секциях, hover-подъём на всех карточках | база компонентов |
| `→` в конце каждой ссылки/кнопки | «Открыть день 1 →» и др. |
| Декоративные номера/подписи без смысловой последовательности | нет — ок |
| Отсутствие единого визуального «якоря» (кроме цвета) | нет ни фотографии, ни типографической сцены, ни материала |
| Все радиусы одинаковые, «мягкость» вместо иерархии | 20px на карточках, 14px кнопки, 12px поля — без системы |

Дополнительно: **нет арт-дирекшна**. Нет решения, как выглядит «человек» в этом продукте (фото?
иллюстрация? ничего?), нет типографической сцены, нет материала/фактуры, нет контраста масштабов.
Копирайт сильный, а визуальный язык нейтрален — поэтому весь бренд держится на терракоте и серифе.

## 3. Что было сделано хорошо (сохранить)

- Тёплая, не медицинская палитра; нет «клинического синего» и «розового женского».
- Спокойный тон, много воздуха, крупные кнопки, мобильный приоритет 360 px.
- Копирайт и структура лендинга по `11-copy.md` — сильная часть, её не трогаем.
- Доступность: контраст AA, тач-зоны, axe — сохраняем как floor.
- Дизайн-система и токены как механика (Tailwind 4, компоненты) — сохраняем, меняем решения.

## 4. Что должно измениться в принципе

1. **Одно решение на ось, но решительное.** Цвет — не «тёплый фон + акцент для кнопок», а
   архитектура: поле бренда, бумага, чернила, один сигнальный цвет. Типографика — не «сериф для
   заголовков», а голос с масштабом, ритмом и италиком.
2. **Композиция важнее декора.** Асимметрия, полноэкранные поля, крупные типографические сцены,
   линии вместо карточек. Декор (арки, круги) убираем или делаем частью одного осмысленного образа.
3. **Медиа вместо пустоты.** Либо арт-дирекшн-фотография (реальные женщины, обычные моменты, плёнка),
   либо один сильный язык иллюстрации. Не «абстрактная органика» как заглушка.
4. **Один момент движения** на страницу вместо fade-up на каждой секции.
5. **Разные интерфейсы — разные ритмы**: лендинг — редакционный, онбординг — тихий и ясный,
   `/app` — рабочий инструмент, а не «дашборд из карточек».

## 5. Критерий готовности редизайна

Скриншот 1440 px можно показать арт-директору без стыда: он не угадывает, что это «сделал AI»,
видит один бренд-идею, читает иерархию за 3 секунды и может назвать 1–2 приёма, которых нет
у конкурентов. Подробный чек-лист — [`.agents/skills/design-opora/SKILL.md`](../../.agents/skills/design-opora/SKILL.md).
