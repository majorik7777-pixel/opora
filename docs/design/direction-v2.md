## 2. Типографика (роли перевёрнуты)

- **Голос/интерфейс — Onest** (Google Fonts, кириллица): H1–H3, навигация, кнопки, поля, подписи,
  лиды. Гротеск ведёт — это главное отличие от AI-дефолта «серифный заголовок + всё остальное».
  Альтернатива для проверки: Golos Text (уже стоит) или лицензионный TT Commons (есть кириллица).
- **Антиква — Literata** (Google Fonts, кириллица): только «события» — цитаты, письма, тексты уроков,
  дневниковые заготовки, крупные редакционные вставки, финальный отчёт. Не для каждого заголовка.
- **Мета/цифры — IBM Plex Mono**: номера дней, даты, счётчики (tabular-nums), только там, где это
  правда последовательность.
- Шкала (mobile → desktop): H1 40/44 → 72/76 (Onest 500/600, tracking −0.02em); H2 30/36 → 44/48;
  H3 22/28 → 28/34; лид 19/30 → 22/34 (Onest 400); reading 17/28 (Literata 400); UI-body 16/24;
  caption 13/18; meta 12/16 (Plex Mono). Вес 400/500/600, без 700+.
- Длина строки: 58–68 знаков body, 40–55 дисплей. Никаких ALL-CAPS-«бровей»; италик — на целой фразе;
  `text-wrap: balance` для заголовков.

## 3. Сетка и композиция

- 12 колонок, max-width 1280, поля 64/40/20, gutter 24/20/16; шаг 8 pt.
- Ритм секций **чередуется**: `paper` → `moss`-поле → фото full-bleed → `paper`; асимметрия 5/7, 4/8, 7/4.
- Линии вместо карточек: редакционные строки, hairline-разделители, подписи на полях; «книжная»
  асимметрия с широкими полями.
- Карточка — только интерактивный модуль: рамка 1px `line`, радиус 4 (плоскости) / 10 (кнопки),
  **без тени**; hover — граница + сдвиг стрелки. 20px «мягкие» карточки уходят.
- Кнопки: 48–56 px, радиус 10; primary — `ink`/`moss` с `paper`-текстом, сигнальный CTA — `wine`
  с paper-текстом; secondary — подчёркнутая ссылка. Без `→` в каждой кнопке.
- Иконки: line 1.5 px, 20/24; без «чипсов» с иконкой над карточкой.

## 4. Фотография и тактильность

- **Фото:** реальные женщины 28–40 в обычных ситуациях: утро, окно, чай, руки, плед, дорога, пустая
  комната, свет на стене; естественный свет, плёночное зерно; без слёз, постановочных улыбок,
  романтических пар. Кропы 3:4, 4:5, 3:2; full-bleed hero.
- **До фотобрифа/съёмки:** временные натюрморты (окно, лён, чашка, свет) с честной пометкой в задаче.
  Unsplash/Pexels нельзя подбирать AI-инструментом по ToS; Wikimedia/CC или заказная съёмка.
  AI-генерация лиц не используется: доверие аудитории и правовые риски РФ.
- **Один тактильный слой на весь продукт:** лёгкое зерно/скан-фактура (SVG/шум) — на фото, обложках,
  пустых состояниях. Не смешивать несколько фактур.
- **Иллюстрация:** один язык — чернильная линия + одно пятно; 2–3 места максимум. Никаких «органик»-
  пузырей и абстрактных арок как главного героя.
- Alt-текст обязателен; декоративное — `aria-hidden`.

## 5. Движение и этика

- Один сценарий на страницу: hero — типографика/фото входят вместе (400–600 ms, ease-out-quint).
  Дальше — без fade-up на каждой секции; hover без подъёма карточек; `prefers-reduced-motion` — всё
  выключено; анимируем только `transform`/`opacity`.
- **Slow-web:** цена и условия — до CTA; никаких таймеров, «осталось 3 места», фейковых рейтингов
  и «4,9★»; «Отменить/Удалить» — рядом и без тёмных паттернов.
- Интерактивные состояния — по [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines).

## 7. Что убрать из текущей версии

- Крем `#F7F3EE` + терракота `#B4654A` + Lora-заголовки как основу бренда.
- Одинаковые скруглённые карточки с тенями; иконки в чипсах; ALL-CAPS eyebrow; `→` в каждой ссылке.
- Абстрактную арку/круги как главную иллюстрацию.
- Fade-up на всех секциях и hover-подъём карточек.
- Сериф как шрифт каждого заголовка (сериф — только «событие», см. §2).

## 9. Критерии приёмки редизайна

- Нет ни одного пункта анти-слоп чек-листа (`.agents/skills/design-opora/SKILL.md`).
- Есть одна бренд-идея (прохладная бумага + мох + вино + гротеск-голос + фото), которая читается
  без подписи «Опора» и не похожа на Calm/Headspace/конкурентов.
- Контраст AA, 360 px без горизонтального скролла, axe 0 serious/critical, reduced-motion.
- Скриншоты 1440/768/360 приложены; копирайт и юридические тексты не изменены.
- Основатель/арт-директор называет 2 приёма, отличающих нас: например, «сериф только в цитатах»
  и «прохладная бумага вместо кремовой».
