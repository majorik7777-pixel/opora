# Направление v4 «Тихий интерфейс» (внедрено)

Дата: 20.11.2026 · Решение: D-036 · Статус: внедрено в лендинг и токены

## Почему меняли v3

v3 (19.11.2026) закрыл продающий слой, но остался редакционным шаблоном: четыре секции подряд
по формуле «заголовок слева + список справа», номера 01–03, hairline-строки, тёмное моховое поле,
AI-стоковые фото. Продукт показывался вяло (маленькая карточка чата поверх фото), доверия было
мало, страница занимала 7 100 px на десктопе и 11 900 px на мобиле.

## Что выбрано

Основатель выбрал из трёх направлений (A «Чертёж», B «Тихий интерфейс», C «Тёплая комната»)
вариант **B** — продукт-первый. Приёмы A перенесены как аккуратные детали: сквозная нумерация
в «Что внутри», моно-цифры дней, подписи-метки.

Ключевая идея: **первый экран показывает продукт**, а не фотографию. Справа — живой экран
приложения: настроение дня, три реплики поддержки, карточка урока. Слева — обещание и цена.

## Токены (globals.css @theme)

| Роль | Значение | Где |
|---|---|---|
| bg / paper | `#FBFAF6` | фон страниц |
| surface | `#FFFFFF` | карточки, экран продукта |
| ink | `#15181A` | текст, primary-кнопка |
| muted | `#5A6266` | вторичный текст (6,3:1) |
| line | `#E6E3DA` | границы, разделители |
| accent / amber | `#B4703A` | маркеры, «события», цифры |
| accent-strong | `#8A5327` | CTA-кнопка (белый текст, 5,3:1), акцентный текст |
| accent-soft | `#F6EBDF` | плашки, выделения |
| sage-soft / moss-soft | `#EDF0EA` | спокойные подложки, настроение |
| sand | `#EFEBE0` | блок приватности |

Радиусы: card 18, button 14, field 12, bubble 16. Тени: `soft` (1 px) и `lift`
(30/70 px с отрицательным spread) — только у экрана продукта и всплывающих карточек.

Типографика: Onest 600 ведёт заголовки (tracking −0.03em), Literata italic — только «событие»
внутри H1 (`*вернуть опору*`) и номера шагов дней. IBM Plex Mono в проекте не используем —
цифры набираем Onest с `tabular-nums`, чтобы не тащить третий шрифт.

## Композиция лендинга

1. **Hero** — 6/6: текст + экран продукта. Факты: 4 колонки (10 мин, 7 дней, 5 сообщений, 990 ₽).
2. **Если сейчас так** — фото 4:5 + список болей с метками (uppercase 12 px).
3. **Не «забудь его»** — 7 дней: чипы 1–7 + три шага с крупными янтарными номерами + фото.
4. **Что внутри** — 5 строк с номерами 01–05, фото блокнота.
5. **Приватность** — песочный блок, «паспорт данных» строками.
6. **Цена** — крупная цифра слева, карточка «что входит» справа, возврат в sage-плашке.
7. **FAQ** — details/summary, «+» янтарный.
8. **Финальный CTA** — фото + карточка с пилюлей «Первый шаг — бесплатно».

Секция ProductDemo (три мокапа) удалена: hero уже показывает продукт, а «Что внутри»
закрывает вопрос «из чего состоит день». Страница стала короче на ~600 px.

## Фото: ограничение

Фото из `apps/web/public/images/photos` — сгенерированные, читаются как AI-сток. В v4 они
убраны из первого экрана (главный герой — интерфейс) и оставлены как эмоциональный фон в
секциях. До арт-съёмки: не добавлять новые AI-кадры, копить бриф (`photo-prompts.md`).
