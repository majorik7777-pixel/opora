# Дизайн и референсы

Версия 1.0 · 19.11.2026
Задача: визуальный язык продукта «Опора» — тёплый, спокойный, взрослый, не медицинский и не инфантильный. Аудитория — женщины 28–40.

---

## 1. Позиция дизайна

**Формула:** Calm × Headspace × современный русский сервис.
Не «розовый женский блог», не «клиника», не «игрушка». Ощущение: **тихая комната, где можно выдохнуть**.

Три принципа:
1. **Спокойствие важнее красоты.** Никаких кричащих акцентов, агрессивных градиентов, стоковых фото плачущих женщин.
2. **Тепло без сюсюканья.** Мягкие формы, бумажные текстуры, человеческий язык. Без эмодзи в каждом предложении.
3. **Ясность важнее эмоции.** Пользователь в уязвимом состоянии: один экран — одно действие, крупные кнопки, понятный следующий шаг.

## 3. Визуальный язык

### 3.1. Палитра

| Токен | HEX | Где |
|---|---|---|
| `bg` | `#F7F3EE` | фон приложения (тёплая бумага) |
| `surface` | `#FFFFFF` | карточки |
| `ink` | `#1F2421` | основной текст |
| `muted` | `#6B6F6A` | вторичный текст |
| `line` | `#E4DCD1` | границы, разделители |
| `accent` | `#B4654A` | CTA, акценты (терракота) |
| `accent-soft` | `#F0DDD3` | подложки акцента |
| `sage` | `#6E7F6A` | спокойные состояния, прогресс |
| `sage-soft` | `#E3E8DF` | подложки |
| `success` | `#5F7F63` | успех |
| `warning` | `#C98A3E` | предупреждения |
| `danger` | `#A64B4B` | кризисные экраны |

Правило: акцент — не больше 10% экрана. Основной фон — тёплый, не белый.

### 3.2. Типографика

- **UI/текст:** Golos Text (или Manrope) — хорошая кириллица, бесплатно.
- **Заголовки лендинга:** Lora (serif) — тепло и «по-человечески», без пафоса.
- **Размеры:** H1 32/40, H2 24/32, H3 20/28, body 16/24, small 14/20, caption 12/16.
- **Вес:** 400/500/600, без 700+.
- **Длина строки:** 60–70 символов.

### 3.3. Формы и пространство

- Сетка 8 pt, базовый отступ 16, секции 48–64.
- Радиусы: карточки 20, кнопки 14, поля 12, пузыри чата 18.
- Тени: мягкие, `0 4 20 rgba(31,36,33,.06)`.
- Кнопки: высота 48–56, на всю ширину на мобильном.
- Иконки: line, 1.5 px, без заливок.

### 3.4. Иллюстрации и графика

- Абстрактные органические формы, «камень/опора», линия горизонта, мягкие пятна.
- Никаких стоковых фото людей, слёз, разбитых сердец, пар.
- Допустимы: текстура бумаги, зерно, рукописные акценты в одном месте.
- Иллюстрации генерировать/рисовать под палитру; не смешивать стили.

### 3.5. Движение

- Плавные fade/slide 200–300 мс.
- Дыхательная анимация на экране «подышать» (медленный круг 4-7-8).
- `prefers-reduced-motion` — отключать анимации.
- Никаких резких вспышек и автоиграющих видео.

## 4. Экраны и макеты (описание)

### 4.1. Лендинг
1. H1 + подзаголовок + CTA «Начать бесплатно» + мягкая иллюстрация справа/снизу.
2. Блок «Если сейчас…» — 4 боли (не могу отпустить, не сплю, всё напоминает, не с кем поговорить).
3. «Что будет за 7 дней» — 3 шага.
4. «Что внутри» — карточки: уроки, практики, дневник, AI-поддержка, отчёт.
5. «Безопасно» — приватность, не медицина, 18+.
6. Цена: 990 ₽, что входит, кнопка.
7. FAQ (6–8 вопросов).
8. Дисклеймер + контакты + оферта.

### 4.2. Онбординг
Один вопрос на экран, прогресс 1/5, крупные варианты, кнопка «Дальше» появляется после выбора. В конце — согласия и кнопка «Начать».

### 4.3. Чат
Шапка: «Опора» + статус «рядом». Пузыри: AI — surface, пользователь — accent-soft. Под полем — быстрые действия: «мне плохо сейчас», «подышать», «записать в дневник». Лимит: «Осталось 3 сообщения сегодня».

### 4.4. Дневник
Сверху — настроение (5 смайлов/шкала), поле текста, кнопка микрофона. Ниже — лента записей по дням с тегами. Пустое состояние — мягкая подсказка.

### 4.5. Программа
Обзор: 7 карточек дней, прогресс, текущий день. День: тема, урок (2 мин), практика с таймером, 2 вопроса рефлексии, кнопка «Завершить день».

### 4.6. Paywall
Заголовок «Продолжить программу», список «что внутри», цена 990 ₽, кнопка «Оплатить», мелким — возврат и безопасность. Без таймеров и давления.

### 4.7. Отчёт
«Твои 7 дней»: динамика настроения (простой график), 3 инсайта, план на 30 дней, кнопка «Скачать/сохранить».

### 4.8. Кризисный экран
Спокойный фон, крупный текст, кнопка «Позвонить 112», список горячих линий, кнопка «Я в безопасности». Без анимаций.

## 5. Компоненты

- Button (primary/secondary/ghost/danger), Input, Textarea, Select, Checkbox, RadioCard.
- Card, Stat, ProgressBar, Streak, MoodPicker, Tag, Avatar (нейтральный).
- ChatBubble, TypingIndicator, QuickAction, LimitNotice.
- ProgramDayCard, LessonBlock, PracticeTimer, ReflectionForm.
- PaywallCard, PriceRow, TrustNote, Disclaimer.
- Modal, Toast, EmptyState, ErrorState, Skeleton.
- Header/Footer, LegalLinks.

Все состояния: default, hover, focus, disabled, loading, error. Фокус видимый — доступность.

---

## 6. Доступность и мобайл

- Контраст AA (проверить текст на фоне).
- Тач-зоны ≥ 44 px.
- Мобильный веб — основная версия; проектировать с 360 px.
- Масштабирование текста до 200% без поломок.
- Не полагаться только на цвет.
- Все формы с подписями, ошибки текстом.

## 7. Что подготовить до кода

1. Figma-файл: токены, компоненты, 8 экранов (лендинг, онбординг, чат, дневник, программа, paywall, отчёт, кризис).
2. Логотип: wordmark «Опора» + знак (две опоры/горизонт).
3. 3–5 иллюстраций в палитре.
4. Иконки: набор line-иконок.
5. Тексты — из `11-copy.md`.
6. Проверка на реальных женщинах 28–40 (5 человек): «какие эмоции вызывает экран», «понятно ли, что делать».

## 8. Анти-паттерны

- розово-лиловые градиенты и «женственность» из стереотипов;
- стоковые фото слёз и объятий;
- медицинский синий и белые халаты;
- мультяшные маскоты;
- таймеры «осталось 10 минут» на paywall;
- бесконечные эмодзи;
- тёмные паттерны: скрытая отмена, сложный возврат.
