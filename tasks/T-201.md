- **Статус:** planned
- **Owner:** не назначен
- **Приоритет:** P0 (первая задача редизайна)
- **Оценка:** 1–2 дня
- **Зависимости:** решение D-032 (выбор направления) ← T-201 стартует после него
- **Write-scope:** `packages/ui/**`, `apps/web/src/app/globals.css`, `apps/web/public/fonts/**`, `docs/design/**`, `docs/adr/**`, `tasks/T-201.md`

## Цель

Перевести дизайн-систему на направление v2: палитра «Лес и мёд», типографика Literata + Onest +
IBM Plex Mono (self-hosted, кириллица), сетка/радиусы/состояния, компоненты с характером вместо
«кремовых карточек с тенями». Сохранить AA-контраст и мобильный 360 px.

## Scope

- Токены в `@theme` (см. `docs/design/direction-v2.md §1–3`), семантические имена, никаких «сырых» hex в компонентах.
- Шрифты: скачать кириллические woff2 (Literata, Onest, IBM Plex Mono), `@font-face` с `unicode-range`, preload.
- Компоненты: Button (квадратнее, honey/ink), Inputs (радиус 6), EditorialRow/Card (рамка без тени), Quote, Stat, Rule, PhotoFrame, Badge/Tag; состояния default/hover/focus/disabled/loading/error.
- Удалить/переосмыслить компоненты v1, которые тянут «нейрослоп» (мягкие тени, pill-кнопки, чипсы).
- `docs/design/README.md` и `direction-v2.md` — статус «принято» после решения.

## Acceptance

- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm build` зелёные; e2e не ломается (классы/семантика).
- [ ] Кириллица рендерится выбранными гарнитурами (скриншоты 360/768/1440).
- [ ] Контраст AA для текста/кнопок/ссылок проверен (APCA — вторично).
- [ ] Никаких теней-«подушек» и одинаковых радиусов: решение задокументировано в токенах.
- [ ] Компоненты имеют все состояния и aria-атрибуты.
